## OpenSubtitles Uploader v1.0.3

Primera versión publicada desde `v1.0.1`: reúne la carga automática de título e
IMDB id, la integración continua completa y la actualización de seguridad de
dependencias.

### Novedades

- **CLI — título e IMDB id automáticos.** `upload` y `analyze` deducen el
  título/estreno y el IMDB id del nombre del archivo de video y, cuando no están
  ahí, del **directorio** que lo contiene (`{tvdb-…}`, `[imdbid-tt…]`,
  `{imdb-tt…}`, `imdbid=tt…` o `tt…` suelto). Se pueden forzar con `--title` y
  `--imdb-id`, que mandan sobre lo deducido.

### Calidad y seguridad

- **Integración continua** (`.github/workflows/ci.yml`): gates bloqueantes en
  Python 3.12 y 3.13 — `ruff check`, `ruff format --check`, `mypy` estricto,
  `bandit` y `pytest` con cobertura — más auditoría de dependencias con
  `pip-audit`.
- **Dependencias**: `cryptography` 45.0.7 → 50.0.1 (el techo `<46` bloqueaba los
  parches de seguridad), `pytest` 8.4.2 → 9.1.1 y `pytest-cov` 7.1.0.
- **Compatibilidad**: los vaults Fernet cifrados por versiones anteriores siguen
  descifrándose (test de vector fijo generado con `cryptography` 45.0.7).

### Correcciones

- **Configuración**: `OPENSUBTITLES_BASE_URL` y `OPENSUBTITLES_HTTP_TIMEOUT` se
  leían antes de cargar el `.env` y se ignoraban; ahora se resuelven de forma
  perezosa. Un timeout inválido cae al valor por defecto en vez de romper el
  arranque.
- **Publicación del release**: los tres assets se suben en pasos secuenciales
  (Linux → macOS → Windows) con el tag fijado, para que no compitan entre sí.
- **Documentación**: corregido el ejemplo de `analyze` (acepta un solo archivo),
  actualizado el ejemplo de tag, y documentadas la resolución de título/IMDB id,
  las variables `.env` opcionales y el cuerpo del release.

### Binarios

Cada archivo incluye la **GUI** (`OpenSubtitlesUploader`) y la **CLI**
(`opensubtitles-uploader-cli`):

| Plataforma | Archivo |
|---|---|
| Windows | `OpenSubtitlesUploader-windows.zip` |
| macOS | `OpenSubtitlesUploader-macos.zip` |
| Linux | `OpenSubtitlesUploader-linux.tar.gz` |

Antes de usarlos, coloca junto al ejecutable un `.env` con la API key y las
credenciales de metadatos; el login de subida se escribe dentro de la app o con
`opensubtitles-uploader-cli login`.
